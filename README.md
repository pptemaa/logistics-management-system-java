# Logistics Management System — Java

Учебный проект по поэтапному переносу [системы управления логистикой на Go](https://github.com/1KrAiDoN1/Logistics-management-system) на Java. Цель — разобраться в устройстве исходной системы и последовательно реализовать её основные сценарии на другом стеке.

> **Статус:** подготовка проекта. Реализация сервисов и инструкции по запуску появятся вместе с работающим кодом.

## Что делает исходная система

Исходный проект организован вокруг нескольких компонентов:

| Компонент | Задача |
| --- | --- |
| Auth Service | Регистрация и аутентификация пользователей |
| Order Service | Создание и управление заказами на перевозку |
| Driver Service | Учёт водителей и их доступности |
| Warehouse Service | Учёт остатков на складе |
| API Gateway | Единая точка входа для клиентских запросов |

В исходном проекте используются REST и gRPC, PostgreSQL, Redis, Kafka и Docker. Это описание **оригинала**; состав и способ применения технологий в Java-версии будут уточняться по мере реализации.

## План Java-версии

Разработка будет идти небольшими самостоятельными этапами. На каждом этапе в репозиторий будут добавляться код, необходимые настройки и проверка реализованного поведения.

1. Создать основу Java-проекта и выбрать первый сервис.
2. Реализовать его минимальный рабочий сценарий и тесты.
3. Добавить хранение данных и миграции, когда они понадобятся сценарию.
4. Постепенно перенести остальные сервисы и взаимодействие между ними.
5. Добавить контейнеризацию и инструкции по локальному запуску готовой системы.

План может меняться после изучения деталей исходного кода. Текущий прогресс будет отражаться в этом README и в истории коммитов.
